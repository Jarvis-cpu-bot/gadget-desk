# The Gadget Desk

Consumer hardware reviews for people mid-purchase-decision. High-key pastel studio-sweep palette (`#F2F4F7` seamless-white, `#1A1D21` ink, `#FF5C39` review-flag orange) carries the product photography like a real studio backdrop. Archivo's variable width axis stands in for an expanded display face over Archivo body text — one family, two widths, so the pairing never drifts off-brand. The signature move is a caliper spec readout: tick-mark dimension rules with monospaced value slots, echoing the calipers reviewers actually use, reused across the hero, the method section, and every verdict card.

## Run

```bash
npm install
npm run dev
```

Open http://localhost:3000 (or the assigned port via `npm run dev -- -p 3003`).

```bash
npm run build   # production build
npm run lint    # eslint
```
